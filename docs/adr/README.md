# Architecture decision records

This directory holds suite-wide decisions, the ones that cut across addons: layout, build and release, conventions, and the shared `Cav7/Core`. Each ADR captures one decision: the context, what was decided, and why.

Addon-specific decisions live with their addon, under `src/addons/Cav7/<AddonId>/docs/adr/`, not here. Addons that arrive with their own ADRs keep them in their own directory. See [`CONTEXT-MAP.md`](../../CONTEXT-MAP.md) for the context layout.

Name files `NNNN-short-title.md`, for example `0001-monorepo-conventions.md`.
