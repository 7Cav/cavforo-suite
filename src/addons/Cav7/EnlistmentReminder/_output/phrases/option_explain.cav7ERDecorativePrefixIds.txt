The thread prefix IDs that ride alongside a processing status without being one, such as S1, RTC and the "!!!" modifier. Nothing is routed or suppressed by them; they are listed here only so the add-on can tell a prefix it has no opinion about from one nobody has told it about yet. A prefix on a queue thread that is listed neither here, nor as an in-processing status, nor as an enlistment type is reported once per scan so a status the configuration has not caught up with is visible. Enter one ID per line or separate with commas. Default: 66, 68, 110 (S1, RTC, "!!!").
