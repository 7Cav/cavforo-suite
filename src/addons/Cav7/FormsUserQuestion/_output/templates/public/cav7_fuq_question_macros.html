The box a forum user question is answered in. It copies the vendor's type_text macro in snog_forms_question_macros, less its maxlength and minlength. Those read type_data, which a question converted from Text keeps, so the browser would go on enforcing a limit the server no longer applies. The box is the user picker, XenForo's autocomplete box pointed at the addon's own lookup, Pub\Controller\Lookup, rather than members/find. "Forum user" uses single mode. "Forum users" uses multiple mode, as search_form_macros::user does, and each pick appends the name and a ", " separator. {$formData|raw}
