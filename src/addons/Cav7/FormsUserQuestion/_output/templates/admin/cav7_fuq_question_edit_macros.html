The options a forum user question has of its own, in the question editor. They follow the vendor Text branch of snog_forms_question_edit_macros::question_types, keeping placeholder and default answer and leaving out regex, length limits and expected answers, which do nothing for these types. The vendor save maps fields to columns only for its own types, so Cav7\FormsUserQuestion\Snog\Forms\Admin\Controller\Questions saves these two, under field names of the addon's own.
